# capitalize

<Signature code="capitalize(str: string): string" />

<SourceLink href="/source/docs-site/typedoc-src/utils/string-ts/#L25" label="string.ts:25" />

Capitalizes the first letter of a string

**Parameters**

- `str` (string) — The input string

**Returns**

- `string` — String with first letter capitalized

**Example**

```typescript
capitalize('hello') // 'Hello'
capitalize('WORLD') // 'WORLD'
capitalize('') // ''
```
