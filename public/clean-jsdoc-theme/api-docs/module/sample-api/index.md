# sample-api

<SourceLink href="/source/index-js/#L75" label="index.js:75" />

A small, fully-documented sample module that exists purely to demonstrate what an **API reference page** looks like when generated by `clean-jsdoc-theme`. It is not a real library — it is a showcase of the common JSDoc constructs (classes, methods, params, returns, examples, typedefs, and cross-references) and the theme's authoring components, all written directly in this doc comment.

<Callout type="info">
  Everything below — this callout, the stepper, and the tabs — is authored inline in the `@module` doc comment. The same `[!NOTE]` / `[!TIP]` / `[!WARNING]` / `[!CAUTION]` markers work too.
</Callout>

## Quick start

<Steps>
  <Step label="Initialize the cache">
    Create a [Cache](/module/sample-api#cache), optionally capping how many entries it holds:

    ```
    const cache = new Cache({ maxSize: 2 });
    ```
  </Step>

  <Step label="Store some values">
    `set()` returns the cache, so calls chain:

    ```
    cache.set('a', 1).set('b', 2);
    ```
  </Step>

  <Step label="Read them back">
    `get()` returns the value and marks the entry as recently used:

    ```
    cache.get('a'); // => 1
    ```
  </Step>
</Steps>

Install it with your package manager of choice:

<Tabs>
  <Tab label="npm">
    ```
    npm install --save-dev jsdoc clean-jsdoc-theme
    ```
  </Tab>

  <Tab label="pnpm">
    ```
    pnpm add -D jsdoc clean-jsdoc-theme
    ```
  </Tab>
</Tabs>

## Static Methods

<MemberHeading id="createcache" depth="3" name="createCache" sig="createCache(entries, options) -> Cache" />

<MemberMeta badges="static" sourceHref="/source/index-js/#L201" sourceLabel="index.js:201" />

Create a [Cache](/module/sample-api#cache) pre-populated from an object of key/value pairs.

**Parameters**

- `entries` (Object.\<string, \*>) — Initial entries to seed the cache with.
- `options` (CacheOptions, optional) — Options forwarded to the [Cache](/module/sample-api#cache) constructor.

**Returns**

- `Cache` — A new, seeded cache.

**Example**

```js
const cache = createCache({ a: 1, b: 2 }, { maxSize: 10 });
cache.get('b'); // => 2
```

## Other

<MemberHeading id="cacheoptions" depth="3" name="CacheOptions" sig="CacheOptions" />

<MemberMeta sourceHref="/source/index-js/#L85" sourceLabel="index.js:85" />

Options accepted by the [Cache](/module/sample-api#cache) constructor.

**Properties**

- `maxSize` (number, optional, default: 100) — Maximum number of entries to keep before the least-recently-used entry is evicted.
- `ttl` (number, optional, default: 0) — Time-to-live for an entry in milliseconds. `0` disables expiry.

**Type**

`Object`

<MemberHeading id="cache" depth="3" name="Cache" sig="Cache" />

<MemberMeta badges="static" sourceHref="/source/index-js/#L100" sourceLabel="index.js:100" />

A tiny in-memory, least-recently-used (LRU) cache.

This class is a demo of how `clean-jsdoc-theme` renders a documented class: the signature, the constructor, properties, and each method get their own section with parameters, return types, and examples.

**Parameters**

- `options` (CacheOptions, optional, default: "{}") — Configuration for the cache.

**Example**

Basic usage

```js
const cache = new Cache({ maxSize: 2 });
cache.set('a', 1);
cache.set('b', 2);
cache.get('a'); // => 1
```

- **See:**
  - [CacheOptions](/module/sample-api#cacheoptions)
